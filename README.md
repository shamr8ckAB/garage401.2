# GARAGE401 — макеты сайта

Три варианта дизайна для автомастерской GARAGE401 (г. Королёв).

| Страница | Файл |
|---|---|
| Все макеты | `index.html` |
| A — Ночная смена | `variant-A-nochnaya-smena.html` |
| B — Заказ-наряд | `variant-B-zakaz-naryad.html` |
| C — Гайка 401 | `variant-C-gayka-401.html` |
| Откуда взята информация | `istochniki.html` |

Каждый файл автономный: шрифты и фото встроены, сборка не нужна.
Макеты закрыты от индексации (`noindex` + `robots.txt`), чтобы не конкурировать в поиске с рабочим сайтом мастерской.
